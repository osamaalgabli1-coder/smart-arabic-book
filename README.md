# نظام المحاسب المطور

أنشئ تطبيق محاسبي عربي احترافي للأندرويد والويب باسم:

نظام المحاسب المطور



العنوان الظاهر أعلى التطبيق داخل مستطيل بعرض الشاشة:



نظام المحاسب المطور



إعداد وتطوير: أسامة الجبلي



الإصدار: 1.0



تصميم الواجهة الرئيسية



تكون الواجهة الرئيسية عبارة عن بطاقات متوسطه وأنيقة تحتوي على:



1- إضافة العملاء



2- إضافة الصناديق



3- إضافة سند جديد



4- إضافة حوالة جديدة



5- كشف الحساب



6- التقارير



7- النسخ الاحتياطي



8- الاستعادة



9- إعدادات الشركة



10- تصدير البيانات



11- تعديل وتطوير البرنامج



12- إنشاء تطبيق مستقل



إدارة العملاء



تتضمن:



- إضافة عميل.

- تعديل عميل.

- حذف عميل.

- رقم الهاتف.

- العنوان.

- الملاحظات.

- الرصيد الافتتاحي.

- صورة العميل (اختياري).



إدارة الصناديق



- إنشاء عدد غير محدود من الصناديق.

- صندوق رئيسي.

- صندوق فرعي.

- رصيد افتتاحي.

- حركة الصندوق.



السندات والقيود



إنشاء سند بسيط يحتوي على:



- التاريخ.

- العميل.

- الصندوق.

- البيان.

- المبلغ.

- نوع العملية.



أنواع العمليات:



- له.

- عليه.

- قبض من العميل إلى الصندوق.

- صرف من الصندوق للعميل.

- تحويل بين الصناديق.

- قيد تسوية.



يقوم النظام بتحديث الأرصدة تلقائياً.



الحوالات



إضافة حوالة جديدة تحتوي على:



- رقم الحوالة.

- المرسل.

- المستلم.

- نوع الحوالة.

- مبلغ الحوالة.

- عمولة صادرة (اختيارية).

- عمولة واردة (اختيارية).

- تاريخ الحوالة.

- حالة الحوالة.



كشف الحساب



إنشاء كشف حساب احترافي يتضمن:



- اسم العميل.

- الهاتف.

- الفترة.

- الرصيد السابق.

- الحركة.

- الرصيد الحالي.

- إجمالي له.

- إجمالي عليه.

- إجمالي القبض.

- إجمالي الصرف.

- الرصيد النهائي.



التقارير



تقرير إجمالي العملاء.



تقرير إجمالي الصناديق.



تقرير الحوالات.



تقرير السندات.



تقرير الأرصدة.



تقرير الأرباح من العمولات.



تصدير البيانات



إضافة أزرار:



- تصدير كشف العملاء الإجمالي PDF.

- تصدير كشف العملاء التفصيلي PDF.

- تصدير Excel.

- مشاركة عبر واتساب.

- حفظ في الجهاز.



بيانات الشركة



شاشة خاصة لإضافة:



- اسم الشركة.

- الشعار.

- الهاتف.

- العنوان.

- البريد الإلكتروني.

- الملاحظات.



وتظهر تلقائياً أعلى كشف الحساب والفواتير والتقارير.



الإشعارات



عند إضافة أي عملية:



- إنشاء صورة إشعار تلقائية.

- إرسال رسالة نصية للعميل.

- إرسال صورة الإشعار عبر واتساب أو تيليجرام.



مثال:



تم إضافة عملية جديدة إلى حسابكم.



المبلغ: 5000 ريال



الرصيد الحالي: 25000 ريال



شكراً لتعاملكم معنا.



النسخ الاحتياطي



إنشاء قسم خاص:



نسخة احتياطية إلى ملفات الجهاز.



استعادة من ملفات الجهاز.



نسخة احتياطية إلى تيليجرام.



استعادة من تيليجرام.



اختيار قناة أو بوت تيليجرام لحفظ النسخ.



إعدادات متقدمة



إضافة شاشة:



تعديل وتطوير البرنامج بنفسي.



تتضمن:



- محرر واجهات.

- محرر النصوص.

- محرر الألوان.

- تعديل الشعار.

- تعديل اسم التطبيق.

- تعديل التقارير.



إنشاء تطبيق مستقل



إضافة شاشة:



تحويل التطبيق إلى تطبيق أندرويد مستقل.



تتضمن:

- تصدير المشروع بالكامل.

- واجهة عربية بالكامل.
